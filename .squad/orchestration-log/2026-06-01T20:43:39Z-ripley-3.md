## Justifications for Non-Standard Choices

### Lambert's Deviations — All Justified

1. **`isAdminPanelOpen` boolean instead of `panelShowStates`** — Admin overlay doesn't participate in flex layout math; adding to panelShowStates would break column width computation. Correct design for v1.

2. **Raw fetch instead of httpClient** — httpClient's 401-throw interceptor would prevent rendering per-status error messages. Plan explicitly requires distinct 401/409/timeout/4xx/5xx messages. Raw fetch is justified.

3. **Jest moduleNameMapper for Fluent ESM → CJS** — Fluent v9 ships ESM-only; jsdom/Jest can't handle without transformation. Well-known workaround (Microsoft docs reference).
