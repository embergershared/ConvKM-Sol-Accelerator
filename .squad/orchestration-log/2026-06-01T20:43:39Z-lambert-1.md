## Key Decisions

1. **Panel state:** Separate `isAdminPanelOpen: boolean` (not `panelShowStates`) to preserve flex layout math
2. **Raw fetch:** Needed for per-status error handling without httpClient 401-throw interceptor pre-empting response
3. **Fluent v9 only:** All components from `@fluentui/react-components` (no v8)
4. **Unsaved-changes:** Two-layer protection: in-panel Dialog + `beforeunload` listener
5. **Accessibility:** `aria-live="polite"` on status, focus management, `aria-label` on action buttons
6. **Whitespace trimming:** Compared before publish to prevent false "unchanged" state on whitespace-only edits
